# Customer Segmentation Project

## Overview
This project aims to perform customer segmentation using customer data from the `MallCustomer.csv` dataset. By applying Exploratory Data Analysis (EDA) and segmentation models, we will group customers into distinct segments to support targeted marketing strategies and improve customer service.

## Dataset
The `MallCustomer.csv` dataset contains customer attributes such as Customer ID, gender, age, annual income, and spending score.

## Project Structure
- `eda/`: Contains Python scripts for Exploratory Data Analysis of the MallCustomer dataset.
- `segment_model/`: Contains Python scripts for developing and validating customer segmentation models.

## Exploratory Data Analysis (EDA)
The EDA process includes:
- Data Analysis
- Data Visualization
- Statistical Analysis

## Segmentation Model
The segmentation model will be developed using clustering techniques. The process includes:

- **Feature Selection:** Identifying relevant features for customer segmentation.
- **Model Selection:** Evaluating different clustering algorithms, such as K-Means and Hierarchical Clustering.
